03JAX routed-MoE kernel

Pallas MoE Kernels

A fused approximate-GELU routed-MoE forward path that tiles the expert hidden dimension and avoids materializing the complete intermediate tensor.

Evidence: 1.84× end-to-end L4 speedup and approximately 81% lower measured XLA peak memory for the documented source geometry.

An exact 10-million-parameter decoder-only transformer trained from scratch to add every ordered pair of integers from 0 through 999.
