01 / Problem

Build a transformer whose result can be evaluated exhaustively.

The model is trained to add every ordered pair of integers from 0 through 999. The domain is finite and complete, making it possible to test every input rather than infer quality from a small sample.

02 / Design

An exact 10-million-parameter decoder-only model.

01Deterministic one-million-pair domain
02Answer-only causal objective
03JAX / Flax NNX training
04Greedy autoregressive exhaustive evaluation
  • Five decoder blocks, model width 320, five attention heads, and FFN width 2,480.
  • Learned absolute position embeddings, Pre-LayerNorm, and tied token/output weights.
  • A 14-token vocabulary containing digits, spaces, plus, and equals.
  • Answers are reversed so generation follows the direction of carry propagation.

04 / Scope and limitations

A result for a fixed mathematical domain.

  • The exhaustive result applies only to the documented representation and the fixed 0–999 domain.
  • It is not a claim about four-digit or arbitrary-length addition.
  • The standalone MoE run is reported separately and does not achieve the dense model's perfect complete-domain result.
