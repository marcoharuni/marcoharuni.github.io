# Marco Haruni portfolio website

A static, responsive portfolio for GitHub Pages. It has no framework, no build step, no remote font dependency, and no empty placeholder sections.

## Publish on GitHub Pages

1. Extract this archive.
2. Replace the current contents of `marcoharuni/marcoharuni.github.io` with the extracted files.
3. Commit and push to the `main` branch.
4. In GitHub, open **Settings → Pages** and confirm the site is deployed from the root of `main` (or keep the repository's existing Pages setting).

The archive is structured so `index.html` is at the repository root.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Main files

- `index.html` — home page
- `work/` — project index and four case studies
- `assets/css/styles.css` — responsive design
- `assets/resume/` — two PDF resumes
- `favicon.svg`, PNG icons, and `og-image.png` — browser and social previews
- `robots.txt`, `sitemap.xml`, `site.webmanifest`, `.nojekyll`
